# 财经视频引擎智能动画语法库

调用 `启用智能动画.sh` 后，路由器按整个 cue 的标题、章节与旁白语义选择语法。选择结果只是生产计划，仍须人工核对；不得把关键词命中直接当成最终镜头设计。

| 语法 | 主引擎 | 适用 | 禁用 / 数据要求 |
|---|---|---|---|
| `fund-flow` | D3 + GSAP | 资金流入、流出、融资、申购、赎回、资金分配 | 数值必须来自 `product-facts.md`；没有数据只做标明“机制示意”的路径图 |
| `cashflow-waterfall` | D3 + GSAP | 营收、成本、利润、自由现金流桥 | 必须有同口径起点、增减项、终点和来源 |
| `line-bar-reveal` | D3 + GSAP | 同比、环比、价格、ETF每日值、估值趋势 | 必须有日期、单位、区间和来源；禁止假K线 |
| `hero-morph` | GSAP | 同一核心对象跨章重排、聚焦、遮罩和状态变化 | 禁止只换文字或整页淡入；对象ID必须稳定 |
| `risk-path` | GSAP SVG | 诈骗、攻击、清算、政策或业务风险传导 | 节点必须对应脚本机制；装饰箭头不算证据 |
| `timeline-focus` | D3 + GSAP | 事件发展、政策阶段、历史节点 | 日期不确定时必须标“待核实”，不得制造精确日期 |
| `comparison-split` | GSAP | BTC/ETH、多空、股票/凭证、公司对比 | 两侧必须使用同一比较维度，禁止错位比较 |
| `tutorial-state-machine` | GSAP | 核验、钱包操作、步骤、行动清单 | 每一步必须改变对象状态并给出成功/失败反馈 |
| `motion-canvas-shot` | Motion Canvas | 多层机制、复杂因果、关键高潮镜头 | 仅在普通DOM/SVG难以清晰表达时采用，计划必须写必要性；不得每个cue都用 |

## 共同实现契约

- GSAP时间线必须 `paused: true`、有限、可seek，并以合成ID注册到 `window.__timelines`。
- D3只计算真实数据对应的几何、比例尺和布局，运动仍接入同一确定性时间轴。
- Motion Canvas镜头必须导出确定时长资产或接入同一绝对时间轴，禁止真实时钟和未设种子的随机数。
- 1—2个Hero至少跨3章推进。旧场景先隐藏，Hero使用独立连续轨，不复制双份制造重影。
- 字幕只由真实配音时间轴驱动；背景图库、品牌资产与财经视频引擎现有验收规则继续生效。
